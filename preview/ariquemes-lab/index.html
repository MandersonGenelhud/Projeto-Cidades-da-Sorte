05 / PERGUNTAS FREQUENTES

Informação sem
complicação.

Esta é uma proposta de interface, pronta para ser avaliada antes da integração com o sistema existente.

Posso participar de sorteios nesta prévia?

Não. Esta demonstração é somente visual. Não há inscrições, sorteios, cobranças, pagamentos ou números disponíveis.

Os cartões representam prêmios confirmados?

Não. Os três cartões mostram conceitos de interface. Não há prêmios, datas, valores ou parceiros anunciados.

Onde está a plataforma oficial?

O endereço oficial continua sendo ariquemesdasorte.com. Este laboratório é totalmente separado.

O que falta antes do lançamento?

Validação do regulamento e do modelo operacional, integração com os dados reais, testes de segurança, acessibilidade e navegação em celulares.
