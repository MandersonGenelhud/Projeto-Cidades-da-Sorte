# Projeto-Cidades-da-Sorte
Cidades da sorte são vários sites de sorteios de cada cidade do País!

## Ferramentas

- [**ZapAuto**](whatsapp-automacao/): automação de WhatsApp com agente de IA que atende, lembra da conversa, responde sobre o negócio e marca horários, além de envio em massa, respostas automáticas e agendamentos.
